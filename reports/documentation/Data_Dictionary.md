# Data Dictionary

| Column Name | Data Type | Description |
|--------------|-----------|-------------|
| CustomerID | Integer | Unique identifier of customer |
| Gender | Category | Customer gender |
| Age | Integer | Customer age |
| Income | Float | Annual income |
| SpendingScore | Integer | Customer spending score |
| PurchaseAmount | Float | Amount spent per purchase |
| Region | Category | Customer location |
| Churn | Binary | Whether customer left |
