# Customer Lifetime Value (CLV) Prediction

## Phase Overview

Customer Lifetime Value (CLV) Prediction is one of the most valuable predictive analytics applications in customer relationship management. While customer segmentation helps classify customers based on their historical purchasing behavior, CLV prediction estimates the future revenue that each customer is expected to generate for the business.

In this phase, a machine learning regression model was developed to predict future customer value using historical transaction data. Instead of creating an artificial CLV score, a time-based approach was adopted by separating historical transactions from future transactions. This methodology closely resembles real-world business scenarios and provides a more realistic and interview-defendable solution.

The final output of this phase is a trained machine learning model capable of estimating Customer Lifetime Value for every customer, enabling businesses to make informed decisions regarding customer retention, marketing investments, and long-term profitability.

# Methodology

Instead of directly predicting historical revenue, a time-based prediction framework was implemented.

The transaction history was divided into two chronological periods:

## Observation Period

Historical customer transactions used for feature engineering.

Customer behavior during this period was summarized into customer-level features.

## Holdout Period

Future customer transactions used to calculate the actual Customer Lifetime Value (CLV).

The total revenue generated by each customer during the holdout period was considered as the target variable for supervised machine learning.

This approach prevents data leakage and closely mimics how CLV prediction is performed in production environments.

# Customer Feature Engineering

Customer-level features were generated using only the observation period.

The engineered features include:

## RFM Features

- Recency
- Frequency
- Monetary

## Quantity Features

- Total Quantity Purchased
- Average Quantity Purchased
- Maximum Quantity Purchased

## Revenue Features

- Average Revenue
- Maximum Revenue
- Revenue Standard Deviation

## Product Features

- Number of Unique Products Purchased
- Average Products per Invoice

## Behaviour Features

- Active Months
- Purchase Span
- Weekend Purchase Rate

These features summarize the historical purchasing behaviour of every customer and serve as the predictor variables for the regression models.

---

# Customer Lifetime Value Target

The Customer Lifetime Value (CLV) target was calculated using transactions from the holdout period.

For each customer,

```
CLV = Total Revenue Generated During Holdout Period
```

Customers with no purchases during the holdout period were assigned a CLV value of zero.

Using future revenue as the target variable enables the machine learning model to learn the relationship between historical customer behaviour and future business value.

# Machine Learning Models

Multiple regression algorithms were trained and evaluated.

The following models were considered:

- Linear Regression
- Ridge Regression
- Lasso Regression
- Decision Tree Regressor
- Random Forest Regressor
- Gradient Boosting Regressor
- Extra Trees Regressor

Training multiple baseline models provides an objective comparison and helps identify the best-performing algorithm.

# Evaluation Metrics

Each regression model was evaluated using standard regression metrics.

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

The final model was selected based on overall predictive performance rather than relying on a single evaluation metric.
